# 📘 Day 5 --- 실습: 안전한 백업 및 아카이빙 스크립트

## 🎯 오늘의 목표

월\~목에 배운 `find`, `tar`, `gzip`, `cp`, `chmod`를 하나의 Shell
Script로 조합하여 특정 디렉토리를 압축 백업하고, 백업 파일을 본인만
접근할 수 있도록 보호하는 실습을 진행했다.

------------------------------------------------------------------------

## 1️. 오늘 구현한 백업 작업

전체 작업 흐름은 다음과 같다.

``` text
백업 대상 확인
    ↓
   압축
    ↓
BackUp 디렉토리에 복사
    ↓
 권한 제한
    ↓
백업 파일 확인
    ↓
rm으로 임시 압축 파일 삭제
```

------------------------------------------------------------------------

## 2️. 최종 작성한 스크립트

``` bash
#!/bin/bash

cd ~/Workspace

# 1. 백업 대상 파일 목록 확인
backup_dir=~/Workspace/practice
link=backup_$(date "+%Y%m%d").tar.gz
find $backup_dir

# 2. 압축
tar -czvf $link $backup_dir
cp $link BackUp/$link

# 3. 권한 제한
chmod 600 BackUp/$link

# 4. 백업 성공 확인
ls -l BackUp
tar -tzf BackUp/$link

# 5. 임시 압축파일 삭제
rm $link
```

------------------------------------------------------------------------

# 💡 핵심

> **여러 Linux 명령어를 Shell Script로 연결하여,
> 파일 확인 → 압축 → 복사 → 권한 설정 → 검증 → 정리까지 하나의 백업 작업으로 자동화했다.**
