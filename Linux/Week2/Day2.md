# 2주차 Day 2 --- 파일 탐색과 압축

## 1. find

`find`는 **디렉터리 트리를 실제로 순회하면서 파일을 찾는 명령어**이다.

``` text
find
  ↓
디렉터리 트리를 실제로 탐색
  ↓
각 파일마다 조건 검사
  ↓
조건에 맞는 파일 출력
```

### 핵심

-   실제 디렉터리 구조를 직접 탐색한다.
-   각 파일을 확인한 뒤 조건에 맞으면 출력한다.
-   새로 생성된 파일도 바로 검색할 수 있다.

### 기본 사용법

``` bash
find [검색할 디렉터리] [조건]
```

예시:

``` bash
find ~/practice -name "*.txt"
```

------------------------------------------------------------------------

## 2. locate

`locate`는 **디스크 전체를 직접 탐색하지 않고 미리 만들어진 DB(인덱스)를
조회**해서 파일을 찾는다.

``` text
사전 작업: updatedb
        ↓
전체 파일시스템 스캔
        ↓
파일/디렉터리 정보를 인덱스(DB)에 저장
        ↓
locate 실행
        ↓
디스크를 직접 탐색하지 않고 DB 조회
        ↓
결과 출력
```

### 핵심

-   `locate`는 실제 디스크를 직접 탐색하지 않는다.
-   미리 만들어진 **인덱스 DB**에서 파일명을 검색한다.
-   따라서 `find`보다 빠르게 검색할 수 있다.
-   `updatedb` 이후에 생성된 파일은 인덱스에 반영되지 않아 검색되지 않을
    수 있다.
-   `updatedb`를 실행한 후에는 새로 생성된 파일도 검색할 수 있다.

### 기본 사용법

``` bash
locate 파일명
```

예시:

``` bash
locate a_copy.txt
```

### updatedb

검색 DB를 최신 상태로 갱신한다.

``` bash
sudo updatedb
```

필기에서는 `updatedb`가 전체 스캔 후 인덱스를 갱신하고, cron으로 하루
1회 실행되는 흐름으로 정리한다.

## 3. find vs locate

  구분               `find`                    `locate`
  ------------------ ------------------------- ----------------------
  탐색 방식          실제 디렉터리 트리 탐색   인덱스 DB 조회
  디스크 직접 탐색   O                         X
  최신 파일 검색     O                         `updatedb` 이후 가능
  속도               상대적으로 느림           빠름
  조건 검색          다양한 조건 사용 가능     주로 파일명 검색

### 한 줄 정리

> **find = 지금 디스크를 직접 찾아보기**

> **locate = 미리 만들어 둔 검색 DB에서 찾아보기**

## 4. tar와 gzip

`tar`와 `gzip`은 서로 역할이 다르다.

### tar

`tar`는 여러 파일과 디렉터리를 **하나의 파일로 묶는 역할**을 한다.

``` text
[파일 1] [파일 2] [파일 3]
          ↓
         tar
          ↓
[ 하나의 아카이브 파일 ]
```

`tar` 자체는 **압축 명령어가 아니다.**

------------------------------------------------------------------------

### gzip

`gzip`은 파일을 **압축하는 역할**을 한다.

``` text
[아카이브 파일]
      ↓
    gzip
      ↓
[압축된 파일]
```

따라서 여러 파일을 하나로 묶으면서 동시에 압축하려면 `tar`와 `gzip`을
함께 사용한다.

------------------------------------------------------------------------

## 5. tar -czvf

``` bash
tar -czvf 결과파일명.tar.gz 파일명
```

예시:

``` bash
tar -czvf backup.tar.gz ~/practice
```

### 옵션 의미

  옵션   의미      설명
  ------ --------- -----------------------------
  `c`    create    새 아카이브 생성
  `z`    gzip      gzip으로 압축
  `v`    verbose   처리되는 파일 목록을 출력
  `f`    file      결과 아카이브 파일명을 지정

``` text
tar -czvf
    │││└─ f : 결과 파일명 지정
    ││└── v : 처리 과정 출력
    │└─── z : gzip 압축
    └──── c : 아카이브 생성
```

### `f` 옵션

`f` 옵션 뒤에는 **결과 파일명**이 온다.

``` bash
tar -czvf backup.tar.gz ~/practice
```

여기서:

``` text
backup.tar.gz → 결과 파일명
~/practice    → 묶을 대상
```

따라서 일반적으로 `f`를 옵션의 마지막에 두고 바로 뒤에 결과 파일명을
작성한다.

------------------------------------------------------------------------

## 6. tar와 gzip의 관계

``` text
여러 파일
  │
  ▼
tar
  │
  ▼
하나의 아카이브
  │
  ▼
gzip
  │
  ▼
압축된 아카이브
```

즉,

> **tar = 여러 파일을 하나로 묶기**

> **gzip = 데이터를 압축하기**

둘을 합쳐 사용하면 다음과 같이 된다.

``` bash
tar -czvf backup.tar.gz ~/practice
```

## 7. 오늘의 핵심 정리

### 파일 찾기

``` text
find
→ 디렉터리 트리를 직접 탐색
→ 최신 상태의 파일을 바로 찾을 수 있음

locate
→ 인덱스 DB 검색
→ 빠르지만 DB가 최신 상태가 아닐 수 있음

updatedb
→ locate가 사용하는 검색 DB 갱신
```

### 파일 묶기 / 압축

``` text
tar
→ 여러 파일을 하나로 묶음

gzip
→ 파일을 압축

tar -czvf
→ tar로 묶고 gzip으로 압축
```

### 기억할 것

``` text
find  = 직접 찾기
locate = DB에서 찾기

tar   = 묶기
gzip  = 압축하기
```
