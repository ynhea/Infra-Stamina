# 😳​ Day 4 — 고급 권한

> 핵심: **SUID · SGID · Sticky Bit · ACL**

---

## 🚩​ 1. SUID

**SUID (Set User ID)**

- 파일을 실행하면 **실행한 사용자가 아니라, 파일 소유자의 권한으로 실행**된다.
- 특히 파일 소유자가 `root`인 경우, 일반 사용자가 해당 프로그램을 실행할 때 잠시 `root` 권한이 필요한 상황에서 사용된다.

```bash
find / -perm -4000 -type f
```
- 위의 명령어로 SUID인 파일 목록을 주기적으로 관리해줘야 한다 (보안위험)

```text
-rwsr-xr-x
   ↑
   s = SUID
```

- 일반적인 실행 권한의 `x` 위치에 `s`가 표시된다.

### 일반 실행파일 vs SUID 실행파일

```text
일반 실행
사용자 → 자신의 권한으로 파일 실행

SUID 실행 파일
사용자 → 파일 소유자의 권한으로 파일 실행
```

## 🚩​ 2. SGID

**SGID (Set Group ID)**

- 해당 디렉토리에서 새로 생성되는 파일은 **디렉토리의 그룹을 상속**받는다.
- 소유자는 생성자가 아닌 그룹이다.
- **공유 디렉토리**에서 유용하다.

### SGID 설정

```bash
chmod g+s shared_dir
```

### SGID 표시

```text
drwxrwsr-x
     ↑
     s = SGID
```

---

## 🚩​ 3. Sticky Bit

**Sticky Bit**

- 주로 **공유 디렉토리**에 사용 (/tmp)
- 여러 사용자가 파일을 생성할 수 있음
- 하지만, **삭제**는 **파일 소유자만 가능**하도록 제한

### Sticky Bit 표시

```text
drwxrwxrwt
        ↑
        t = Sticky Bit
```

---

## 🚩​ 4. ACL

**ACL (Access Control List)**

- 특정 사용자에게만 **예외적인 권한**을 주고 싶을 때

### ACL 설정

```bash
setfacl -m u:사용자명:권한 파일명
```

### ACL 확인

```bash
getfacl 파일명
```

---

## 🚩​ 5. 특수 권한 숫자 표기 ⭐

- `chmod`의 가장 앞쪽 숫자를 이용하여 특수 권한을 지정할 수 있다.
- 여러 특수 권한을 조합할 수도 있다.

| 숫자 | 특수 권한 |
|---:|---|
| `4` | SUID |
| `2` | SGID |
| `1` | Sticky Bit |

### 예시

```bash
chmod 4755 file
```

---

## 🚩​ 6. 핵심 요약

> **SUID** → 파일을 **소유자의 권한으로 실행**

> **SGID** → 디렉토리에서 생성되는 파일은 **디렉토리의 그룹 소유**

> **Sticky Bit** → 공유 디렉토리에서 **다른 사용자의 파일 삭제를 제한**

> **ACL** → 특정 사용자나 그룹에게 **예외적인 권한을 추가**
