# 😵​ Day 3 — Linux 권한 체계

## ​🚩​ 1. 목표

Linux에서 파일과 디렉토리에 대한 **권한을 확인하고 변경하는 방법**을 배운다.

| 명령어 | 의미 | 역할 |
|---|---|---|
| `chmod` | Change Mode | 파일/디렉토리의 권한 변경 |
| `umask` | User Mask | 새로 생성되는 파일/디렉토리의 기본 권한을 제한 |
| `chown` | Change Owner | 파일/디렉토리의 소유자 변경 |
| `chgrp` | Change Group | 파일/디렉토리의 소유 그룹 변경 |

---

## ​🚩​ 2. chmod — 권한 변경

`chmod`는 파일이나 디렉토리의 **읽기(r), 쓰기(w), 실행(x) 권한을 변경**하는 명령어이다.

Linux의 권한은 다음과 같이 **3개의 대상 × 3개의 권한**으로 구성된다.

```text
              사용자(u)     그룹(g)      기타(o)
               owner        group       others
              ┌───────┬──────────┬──────────┐
              │  rwx  │   rwx    │   rwx    │
              └───────┴──────────┴──────────┘

                4 2 1      4 2 1       4 2 1
```

### 권한의 숫자값

| 권한 | 숫자 | 의미 |
|---|---:|---|
| `r` | 4 | 읽기 |
| `w` | 2 | 쓰기 |
| `x` | 1 | 실행 |

각 숫자는 순서대로 **사용자(u) → 그룹(g) → 기타(o)**를 의미한다.

---

## ​🚩​ 3. 파일과 디렉토리에서 r, w, x의 차이

필기에서 특히 구분해야 할 부분이다.

| 권한 | 파일 | 디렉토리 |
|---|---|---|
| `r` | 파일 내용 읽기 | 디렉토리 내부 목록 확인 |
| `w` | 파일 내용 수정 | 파일 생성/삭제/이름 변경 |
| `x` | 파일 실행 | 디렉토리 내부 접근 및 `cd` |


특정 권한만 변경할 때는, 심볼릭 모드로 사용하는 게 효율적이며,
전체 권한을 변경할 때는, 숫자 모드로 사용하는 게 효율적이다.

## ​🚩​ 4. umask — 기본 권한 제한

`umask`는 파일이나 디렉토리를 새로 만들 때 적용되는 **기본 권한 제한값**이다.

(보통은 022로 설정된다.)

---

## ​🚩​ 5. chown — 소유자 변경

`chown`은 파일이나 디렉토리의 **소유자(owner)를 변경**하는 명령어이다.

```bash
sudo chown 소유자명 파일명
```

소유자와 그룹을 동시에 변경할 수도 있다.

```bash
sudo chown user2:dev example
```

---

## ​🚩​ 6. chgrp — 소유 그룹 변경

`chgrp`는 파일이나 디렉토리의 **소유 그룹(group)을 변경**한다.

```bash
sudo chgrp dev example
```
