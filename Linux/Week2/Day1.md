# 📘 Day 1 — 파일 관리

## 1. `pwd` — 현재 위치 확인

- `pwd` = **Print Working Directory**
- 현재 작업 디렉토리(CWD)의 절대경로를 확인하는 명령어

### 경로 기호

- `/` → 루트 디렉토리
- `.` → 현재 디렉토리
- `..` → 부모 디렉토리
- `~` → 홈 디렉토리

### 절대경로 vs 상대경로

```text
/home/user/practice/a.txt   → 절대경로
./a.txt                     → 현재 위치 기준
../a.txt                    → 부모 디렉토리 기준
```

**핵심**

> 내가 어디에 있는지(`pwd`)에 따라 상대경로가 가리키는 대상이 달라진다!

## 2. 하드링크(ln) vs 복사(cp) vs 심볼릭링크(ln -s)

### 하드링크 (별로 사용 안 되긴함;)
- 또 다른 이름 (주소 = 우편번호 같은 관계)계
- 원본도 하드링크이므로,,, "원본과 하드링크를 헷갈리지 마세요"는 구라임!
- ㄸ라서 1개를 바꾸면, 다 바뀜

---

### 복사

- 새로운 inode가 생성된다.
- 데이터도 복사된다.
- 원본과 복사본은 서로 독립적이다.

---

### 심볼릭 링크 (바로가기) 

- 심볼릭 링크도 복사처럼 별도의 inode를 가진다.
- 대상 파일의 경로를 저장하고 그 경로를 따라간다. 복사XXXXXX!!!!
- 원본이 삭제되거나 경로가 변경되면 링크가 깨질 수 있다.

## 3. `mv` — 이름 변경 / 이동

파일을 이동하거나 파일 이름을 변경할 때 사용한다. (그냥 매핑내용 변경임!!) ("이동" 자시고 하는 개념없음.)

### 같은 파일시스템 내에서

- inode는 그대로 유지된다.
- 실제 데이터를 통째로 이동시키는 것이 아니다.
- 디렉토리의 파일명 ↔ inode 연결을 변경한다.
- 따라서 같은 파일시스템 안에서는 대용량 파일도 매우 빠르게 이동할 수 있다.

### 다른 파일시스템으로 이동

- 파일시스템마다 inode 체계가 독립적이므로 기존 inode를 그대로 사용할 수 없다.
- 복사 → 원본 삭제와 같은 방식으로 처리되므로 파일 크기에 따라 시간이 오래 걸릴 수 있다.

---

## 4. `rm` — 파일 이름 제거

- 파일을 삭제할 때 사용하는 명령어다.
- Hard Link가 있는 경우 (Link Count가 0이 아니므로) 데이터는 유지된다.

**핵심**

> `rm`은 파일 데이터를 직접 지우는 것이라기보다 디렉토리에서 이름과 inode의 연결을 제거하는 작업이다.

---

### 명령어별 변화

| 명령어 | 핵심 동작 |
|---|---|
| `pwd` | 현재 작업 디렉토리(CWD) 확인 |
| `cp` | 새로운 inode + 데이터 복사 |
| `mv` | 같은 FS라면 이름/위치와 inode의 연결 변경 |
| `rm` | 이름과 inode의 연결 제거 |
| `ln` | 같은 inode를 가리키는 이름 추가 |
| `ln -s` | 대상 경로를 가리키는 새로운 심볼릭 링크 생성 |
