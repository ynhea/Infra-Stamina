# 🐧 4주차 - Day 3

## Variable, if, case

---

## 1️. 목표
1. **Variable(변수)** — 값을 저장하고 재사용
2. **if** — 조건에 따라 분기
3. **case** — 여러 패턴에 따라 분기

---

## 2. 핵심 개념

| 개념 | 영어 | 한 줄 정의 |
|---|---|---|
| **변수** | Variable | 값을 저장하고 `$이름`으로 재사용하는 문법 |
| **조건문** | if | 조건이 참/거짓인지에 따라 다른 명령을 실행 |
| **다중 분기** | case | 여러 조건을 패턴 매칭으로 깔끔하게 처리 |

---

## 3. 내부 동작 원리

### ① Variable (변수)

변수 대입에서는 **등호 앞뒤에 공백이 없어야 한다.**

```bash
name="devuser"      # ✅
name = "devuser"    # ❌
```

공백이 들어가면 bash가 `name`을 명령어로 해석할 수 있다.

---

### ② 변수는 따옴표로 감싸기

위험할 수 있는 코드:

```bash
if [ $1 = "x" ]; then
```

`$1`이 비어 있으면 다음처럼 전개될 수 있다.

```bash
if [ = "x" ]; then
```

따라서 다음처럼 작성한다.

```bash
if [ "$1" = "x" ]; then
```

이 경우 `$1`이 비어 있어도:

```bash
if [ "" = "x" ]; then
```

처럼 정상적인 비교가 가능하다.

---

## 4. if 문

### 기본 구조

```bash
if [ 조건 ]; then
    명령
elif [ 다른조건 ]; then
    명령
else
    명령
fi
```

### 자주 사용하는 조건

| 테스트 | 의미 |
|---|---|
| `-z "$1"` | 문자열이 비어 있는가 |
| `-n "$1"` | 문자열이 비어 있지 않은가 |
| `"$a" = "$b"` | 문자열이 같은가 |
| `-f 파일` | 파일이 존재하는가 |
| `-d 디렉토리` | 디렉토리가 존재하는가 |
| `-eq` | 숫자가 같은가 |
| `-ne` | 숫자가 다른가 |
| `-gt` | 숫자가 큰가 |
| `-lt` | 숫자가 작은가 |

---

## 5. case 문

`if/elif` 조건이 많아질 때는 `case`를 사용하면 여러 패턴을 깔끔하게 처리할 수 있다.

```text
case "$1" in
    패턴1) 명령 ;;
    패턴2) 명령 ;;
    *)     기본값 ;;
esac
```

`*)`는 어디에도 매칭되지 않을 때 실행되는 기본 패턴

---

## 6. 심화 내용

### `[` vs `[[` 차이

```bash
[ "$a" = "$b" ]
```

- 표준 POSIX 테스트 문법
- 오래된 방식이지만 널리 사용됨

```bash
[[ "$a" == "$b" ]]
```

- bash 확장 문법
- 조건 표현에서 더 많은 기능을 제공

`[[ ]]`은 `[ ]`보다 변수 전개로 인한 일부 문제를 줄일 수 있지만, 변수에 따옴표를 붙이는 습관은 계속 유지한다.

---

### exit code와 if의 관계

`if`는 명령의 **종료 상태(exit code)**를 기준으로 판단한다.

```text
명령 실행
    ↓
종료 코드 확인
    ├─ 0        → 성공 → if 조건이 참
    └─ 0이 아님  → 실패 → if 조건이 거짓
```

예:

```bash
if systemctl is-active --quiet sshd; then
    echo "sshd 정상 작동중"
else
    echo "sshd 비활성 상태!"
fi
```

## 🧠 핵심 정리

```text
Variable
→ 값을 저장하고 재사용

if
→ 조건에 따라 실행할 코드를 선택

case
→ 하나의 값을 여러 패턴과 비교

"$변수"
→ 변수 전개 시 안전하게 사용

exit code
→ 명령의 성공/실패 상태
→ if가 조건 판단에 사용하는 핵심 기준
```
