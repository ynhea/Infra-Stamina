## 🛡️ 3. sudo

`sudo`는 허용된 사용자가 특정 명령을 **다른 권한으로 실행**하게 해준다.

일반 사용자로 로그인한 상태에서도 해당 명령만 관리자 권한으로 실행할 수 있다.

> ⚠️ `/etc/sudoers` 등의 sudo 정책에 의해 허용된 사용자만 sudo를 사용할 수 있다.

### SUID와 sudo 비교

| SUID (`passwd`) | sudo |
|---|---|
| 파일 자체에 권한 상승이 설정됨 | sudo 정책에 따라 권한을 위임 |
| 파일 소유자의 권한으로 실행 | 허용된 사용자만 사용 가능 |
| 실행 파일 자체의 특수 권한 | `/etc/sudoers` 등의 정책으로 관리 |
| 예: `passwd` | 예: `sudo` |

### 💡 핵심

```text
SUID
→ "이 프로그램을 실행하면 파일 소유자의 권한을 사용"

sudo
→ "이 사용자가 이 명령을 다른 권한으로 실행하도록 허용"
```

---

## 🔄 4. sudo와 su -

### `sudo`

특정 명령을 높은 권한으로 실행한 뒤 **다시 현재 사용자로 작업**한다.

```bash
sudo <명령어>
```

예:

```bash
sudo whoami
```

---

### `su -`

다른 사용자로 **세션 자체를 전환**한다.

```bash
su - <사용자명>
```

root로 전환하는 경우:

```bash
su -
```

### 📊 비교

| `sudo` | `su -` |
|---|---|
| 특정 명령에 권한 부여 | 사용자/세션 자체를 전환 |
| 필요한 순간에 사용 | 전환된 사용자 셸에서 계속 작업 |
| 명령 단위로 권한 사용 | 전환된 사용자의 권한으로 계속 작업 |

### 한눈에 보기

```text
sudo
현재 사용자
    │
    └── sudo 명령어
            ↓
       높은 권한으로 실행
            ↓
       다시 현재 사용자


su -
현재 사용자
    │
    └── su -
            ↓
       다른 사용자로 전환
            ↓
       전환된 사용자 셸에서 계속 작업
```

## ⚙️ 5. /etc/sudoers와 visudo

sudo를 사용할 수 있는 권한은 `/etc/sudoers` 등의 **sudo 정책**으로 관리한다.

### `/etc/sudoers`

sudo 권한 정책을 정의하는 파일이다.

```text
/etc/sudoers
      ↓
누가 sudo를 사용할 수 있는가?
      ↓
어떤 명령을 실행할 수 있는가?
```

### `visudo`

sudoers를 편집할 때 사용하는 전용 명령어다.

```bash
sudo visudo
```

`visudo`는 저장 과정에서 **sudoers 문법을 검사**하여 잘못된 설정으로 sudo가 동작하지 않는 사고를 예방한다.

> ⚠️ `/etc/sudoers`를 수정할 때는 일반 편집기보다 `visudo`를 사용하는 것이 안전하다.

---

## 🧠 6. 오늘의 핵심 정리

```text
sudo
→ 특정 명령을 다른 권한으로 실행

su
→ 다른 사용자로 전환

su -
→ 다른 사용자의 로그인 환경으로 전환

/etc/sudoers
→ sudo 권한 정책

visudo
→ sudoers 안전 편집 + 문법 검사
```

### ⭐ 꼭 기억하기

> **sudo = 명령에 권한을 빌려쓰기**  
> **su - = 사용자 자체를 바꾸기**
